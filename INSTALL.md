# Install Spoken Hebrew · התקנת Spoken בעברית

[English](#english) · [עברית](#hebrew)

<a id="english"></a>

## English

Hear WoW quests and NPC talk in Hebrew, with Hebrew subtitles. So far it covers the starting zones,
the capitals and most zones up to level 30, and more zones are on the way.

**You need:** WoW Forever and Spoken 3.9.0 or newer.

### With the Spoken Manager (easiest)

1. Download the **Spoken Manager** from [Spoken's releases page](https://github.com/rusty-key/spoken-wow/releases)
   (the newest "Spoken Manager"). On Windows, run `Spoken-Manager-Setup-<version>.exe`. If
   SmartScreen asks, choose **More info**, then **Run anyway**.
2. Open the Manager. On the **Spoken** tab, install or update Spoken.
3. On the **Community** tab, find **Spoken Hebrew (Ivrit)** and press **Install**.
4. Start the game. If it was open, restart it.
5. Type `/sp`. Under **Language**, set **Voice Language** to **Hebrew**. Leave **If a Voice Is
   Missing** on **English**, so quests that have no Hebrew recording yet are read in English.

Done. Talk to a quest giver.

### Without the Manager

1. Download `SpokenCommunity_ivrit-<version>.zip` from
   [Releases](https://github.com/renanbazinin/spoken-ivrit/releases/latest).
2. Extract it into `World of Warcraft\_forever_\Interface\AddOns`. You should get a folder named
   `SpokenCommunity_ivrit`.
3. Do steps 4 and 5 above.

Use the Manager or the zip, not both.

### Something wrong?

- **Hebrew is not in Voice Language:** update Spoken to 3.9.0 or newer and restart the game.
- **You hear English, not Hebrew:** that quest isn't recorded in Hebrew yet, or Voice Language is
  on **Auto**. Auto never picks Hebrew.
- **A line sounds wrong:** [report it](https://github.com/renanbazinin/spoken-ivrit/issues/new/choose).

## עברית

שומעים את המשימות והדמויות ב-WoW בעברית, עם כתוביות בעברית. כרגע יש את אזורי ההתחלה, הבירות ורוב
האזורים עד רמה 30, ועוד אזורים בדרך.

**צריך:** ‏WoW Forever ו-Spoken בגרסה 3.9.0 ומעלה.

### עם Spoken Manager (הכי קל)

1. מורידים את **Spoken Manager** מ[דף הגרסאות של Spoken](https://github.com/rusty-key/spoken-wow/releases)
   (ה-"Spoken Manager" החדש ביותר). ב-Windows מריצים את `Spoken-Manager-Setup-<version>.exe`. אם
   SmartScreen שואל, לוחצים **More info** ואז **Run anyway**.
2. פותחים את המנהל. בלשונית **Spoken** מתקינים או מעדכנים את Spoken.
3. בלשונית **Community** מוצאים את **Spoken Hebrew (Ivrit)** ולוחצים **Install**.
4. מפעילים את המשחק. אם הוא היה פתוח, סוגרים ופותחים אותו מחדש.
5. כותבים `/sp` בצ'אט. תחת **Language**, ב-**Voice Language** בוחרים **Hebrew**. את **If a Voice Is
   Missing** משאירים על **English**, כדי שמשימות שעוד לא הוקלטו בעברית יוקראו באנגלית.

זהו. מדברים עם נותן משימות.

### בלי המנהל

1. מורידים את `SpokenCommunity_ivrit-<version>.zip` מ[דף ה-Releases](https://github.com/renanbazinin/spoken-ivrit/releases/latest).
2. מחלצים אותו לתוך `World of Warcraft\_forever_\Interface\AddOns`. צריכה להיווצר תיקייה בשם
   `SpokenCommunity_ivrit`.
3. ממשיכים בשלבים 4 ו-5 למעלה.

משתמשים במנהל או ב-zip, לא בשניהם.

### משהו לא עובד?

- **אין Hebrew ב-Voice Language:** מעדכנים את Spoken ל-3.9.0 ומעלה, ומפעילים את המשחק מחדש.
- **שומעים אנגלית ולא עברית:** המשימה הזאת עוד לא הוקלטה בעברית, או ש-Voice Language על **Auto**.
  ‏Auto אף פעם לא בוחר עברית.
- **משפט נשמע לא טוב:** [מדווחים עליו כאן](https://github.com/renanbazinin/spoken-ivrit/issues/new/choose).
